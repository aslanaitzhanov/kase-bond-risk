# Проверки публичной сборки — 09.11.2026

Исходник: предоставленный автором `KASE_Bond_Risk_upload (2).zip`.
Это отдельная копия; исходный архив и рабочая папка автора не изменялись.

## Изменения

- Удалён интерфейс записи JSON по произвольному пути на сервере.
  Служебная функция записи также явно запрещает эту операцию.
- Сохранено скачивание CSV, Excel и JSON.
- Исключены справочники выпусков, стартовые реальные облигации, исторические
  рыночные наблюдения и инструмент получения страниц KASE.
- Удалены неиспользуемые импорты этих справочников. Название конвенции
  `30/360 KASE (п. 18)` перенесено в отдельный модуль без рыночных данных.
- Добавлены предупреждения об обработке данных на сервере и отсутствии
  постоянного хранения; приложение не является сервисом KASE.
- Убран адрес привязки 127.0.0.1 из облачной конфигурации, установлен лимит
  загрузки файла 5 МБ. CORS/XSRF-защита оставлена включённой.
- Включены воспроизводимые зависимости для проверенной среды Python 3.12:
  Streamlit 1.67.0, pandas 2.2.3, NumPy 2.3.5, Plotly 7.1.0, openpyxl 3.1.5.
  Это версии среды этой проверки, а не заявление о среде первоначальных тестов.

## Выполнено

- 22 проверки pytest успешно пройдены.
- Все семь разделов проверены через Streamlit AppTest с пустым и заполненным
  синтетическим портфелем: 14 из указанных 22 проверок.
- Проверены цена → YTM для двух методов, знаки стрессов и нулевой сдвиг,
  неизменность входной позиции, CSV/XLSX/JSON round-trip, запрет серверной записи,
  разделение двух сессий и отсутствие встроенных справочников/сетевых клиентов.
- Определения функций и классов в calculations.py, kase_pricing.py, models.py,
  schedule.py, coupon_scenarios.py и validation.py сравнивались через AST:
  совпадают с исходником; изменены лишь указанные импорты.
- На основном исследовательском JSON отдельно сравнены все выходные данные
  портфельной аналитики и четырёх стрессов исходной и публичной версий: совпали.
  Этот пользовательский JSON и его рыночные исходные данные в сборку не включены.
- Сервер Streamlit запущен; health endpoint ответил `ok`, главная страница HTTP 200.
