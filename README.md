# KASE Bond Risk — публичная учебная версия

Учебное приложение для оценки цены и процентной чувствительности облигаций
по введённым пользователем денежным потокам. Это не продукт KASE и не
инвестиционная рекомендация. Подключение к KASE/API отсутствует.

## Что включено

- Ручной ввод и импорт портфеля (CSV, XLSX, JSON).
- Цена из YTM и YTM из цены; полная/чистая цена и НКД при достаточных данных.
- Дюрация Маколея, модифицированная дюрация, выпуклость, стресс-тесты.
- Скачивание данных и результатов; записи по произвольному пути на сервере нет.
- Пустой портфель при запуске; встроенных выпусков, котировок, ставок и
  исследовательского портфеля нет. Пользователь сам отвечает за право использования
  загружаемых данных. Названия методов дисконтирования сохранены для совместимости.

Расчётные функции перенесены из предоставленного автором архива без изменения
формул. Проверки этой сборки описаны в `BUILD_CHECKS.md`; они не заменяют
независимую валидацию всех функций или рыночных исходных данных.

## Важно о данных

В интернет-версии данные отправляются на сервер для расчёта, а не остаются
только на компьютере посетителя. Не вводите персональные, брокерские и
конфиденциальные данные. Постоянное хранение портфеля приложением не предусмотрено.
Скачивайте JSON для сохранения своей работы. Данные сессии могут исчезнуть
при перезапуске или завершении соединения. Это не гарантия удаления всех следов
обработки у провайдера размещения; его условия действуют отдельно.

Для плавающих купонов используются явно заданные сценарные потоки.
Их реакция на TONIA автоматически не моделируется. Показатели характеризуют
чувствительность заданных потоков к YTM, а не полный риск плавающих выпусков.

## Запуск на своём компьютере

Рекомендуется Python 3.12 (на нём проверена эта сборка).

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Размещение через GitHub и Streamlit Community Cloud

1. Распакуйте ZIP. Загружайте содержимое папки проекта, а не сам ZIP.
2. В своём GitHub создайте отдельный репозиторий `kase-bond-risk`.
   Учтите: в публичном репозитории код будет доступен всем.
3. Загрузите файлы так, чтобы `app.py`, `requirements.txt` и `styles.css`
   находились в корне репозитория, рядом с остальными модулями.
   Сохраните папку `.streamlit` и её `config.toml`.
   Не добавляйте `.env`, `secrets.toml`, личные портфели или рабочие архивы.
4. Откройте https://share.streamlit.io/ и войдите через GitHub.
5. Создайте приложение из репозитория: ветка `main`, основной файл `app.py`.
   В расширенных настройках выберите Python 3.12.
6. После развёртывания проверьте адрес приложения на другом устройстве.
   Только после этой проверки делайте QR-код.

Официальные инструкции:
https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app
https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/app-dependencies

Подготовленный архив сам по себе не означает публикацию. Для защиты сохраните
локальную рабочую версию и скриншоты как резерв на случай отсутствия интернета.

## Проверки сборки

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Не добавляйте лицензию на сторонние данные или утверждение об одобрении KASE
без соответствующего разрешения. Авторскую лицензию на код можно выбрать отдельно.
